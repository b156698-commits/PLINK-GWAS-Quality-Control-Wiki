# PLINK / GWAS LLM Wiki

本專案是第十週作業使用的 LLM Wiki 專案。

主題為：

**PLINK / GWAS Quality Control Wiki**

目標是先建立一個以 PLINK / GWAS 為主題的 LLM Wiki，
再使用 Wiki 作為知識來源，產生一份給初學者閱讀的教學型 HTML 簡報。

## 專案流程

資料來源

→ ingest / 整理

→ 查詢 Wiki
→ 整理教學重點
→ 檢查內容
→ presentation/
→ 最終 HTML 簡報
