PLINK 從什麼資料開始？

PLINK binary fileset

  • .bed：genotype data
  • .bim：variant information
  • .fam：sample / family information
study.bed
study.bim
study.fam

基本指令

plink --bfile study

--bfile study 不是指定單一檔案，而是指定共用同一個 prefix 的三個檔案。

在正式進入 QC 前，先確認資料輸入與檔名結構是否正確。

在測試 SNP 與 phenotype 的 association 前，通常會先檢查資料品質、樣本相關性，以及 population structure。

Missingness：先找缺失過多的資料

Variant-level missingness

--geno

移除 missing call rate 太高的 variants。

plink --bfile study --geno 0.02 --make-bed --out qc_geno

Sample-level missingness

--mind

移除 missing genotype rate 太高的 samples。

plink --bfile qc_geno --mind 0.02 --make-bed --out qc_mind
重要：

0.02 是教學範例，不是所有研究都固定使用的 universal threshold。

Wiki：02-missingness.md ｜ Source：S02

MAF & HWE：檢查 variant 品質

MAF

--maf <threshold>

依 minor allele frequency 篩選 variants。

plink --bfile qc_mind --maf 0.01 --make-bed --out qc_maf

HWE

--hwe <p-value>

依 HWE exact-test p-value 篩選 variants。

plink --bfile qc_maf --hwe 1e-6 --make-bed --out qc_hwe
提醒：

0.01 與 1e-6 都是示範值。HWE threshold 過於嚴格時，也可能排除 genuine association signals。

Wiki：03-maf-hwe.md ｜ Source：S02

LD Pruning：建立較獨立的 SNP subset

基本指令

plink --bfile qc_data --indep-pairwise 50 5 0.2 --out ld

<window> <step> <r²> 依序表示：window size、step size、pairwise r² threshold。

輸出檔案

  • ld.prune.in：保留的 variants
  • ld.prune.out：被排除的 variants

常見用途

  • PCA
  • Relatedness / IBD estimation
關鍵提醒：

LD-pruned set 常用於 PCA 或 relatedness，但不能直接推論最終 GWAS association testing 只能使用 pruning 後的 SNP。

Wiki：04-ld-pruning.md ｜ Source：S03

Relatedness：樣本之間是不是太相似？

PLINK 指令

plink --bfile ld_pruned --genome --out relatedness

利用 --genome 做 pairwise IBS / IBD 計算。

核心指標

PI_HAT = Z2 + 0.5 × Z1

PI_HAT 可用來描述 pairwise relatedness。

  • Relatedness estimation 前通常先做 LD pruning。
  • PI_HAT cutoff 不是所有研究都固定相同。
  • 兩個 related samples 中刪誰，要由研究規則決定。
Wiki：05-relatedness.md ｜ Source：S04

PCA：處理 Population Structure

PLINK

plink --bfile ld_pruned --pca --out pca

產生：

  • .eigenvec
  • .eigenval

Concept

Disease ~ SNP + Age + Sex + PC1 + PC2 + PC3

Top PCs 常加入 association model 作為 covariates，以協助校正 population stratification。

提醒：

PLINK 預設輸出 20 PCs，不代表分析模型一定要使用 20 個 PCs。

Wiki：06-pca.md ｜ Source：S05

Association Analysis：SNP 與疾病有沒有關聯？

Phenotype file

FID IID STATUS
F001 I001 1
F001 I002 2
F002 I003 2

PLINK 1.9 常見 case/control coding：

  • 1 = control
  • 2 = case

Covariate file

FID IID AGE SEX PC1 PC2 PC3
F001 I001 70 1 -0.012 0.031 -0.004
F001 I002 66 2  0.008 0.022  0.011

可用 --covar-name AGE,SEX,PC1-PC3 指定使用哪些 covariates。

完整教學範例

plink \
  --bfile qc_final \
  --pheno phenotype.txt \
  --pheno-name STATUS \
  --covar covariates.txt \
  --covar-name AGE,SEX,PC1-PC3 \
  --logistic hide-covar \
  --out gwas_logistic
  • OR > 1 / OR < 1 必須配合 effect allele 解讀。
  • Covariates 需依研究設計決定，不是固定清單。
  • Association ≠ causality。
Wiki：07-association.md ｜ Sources：S05, S06, S08

Manhattan Plot：全基因組哪裡有強訊號？

Multiple Testing

GWAS 同時檢驗大量 variants，因此不能只用一般的 P < 0.05 思考。

GWAS 常用的全基因組顯著性門檻：P < 5 × 10-8

Manhattan Plot

  • X 軸：chromosome / genomic position
  • Y 軸：-log10(P)
  • 點越高 → p-value 越小
提醒：

Genome-wide significance 不等於 causality，顯著結果仍需要後續研究與 replication。

Wiki：08-gwas-results.md ｜ Source：S07

QQ Plot 與整體結果判讀

QQ Plot 在看什麼？

比較 observed association statistics 與 null hypothesis 下的 expected distribution。

  • 大多數點貼近對角線：整體較合理
  • 尾端偏離：可能有 association signals
  • 大量點提早偏離：需進一步檢查

可能要檢查的問題

  • Population structure
  • Relatedness
  • Technical artifacts
  • 其他造成 test statistic distribution 改變的因素
最後提醒：

QQ deviation 不能單獨證明是哪一種問題造成。看結果時，要把 QC、population structure 與研究設計一起考慮。

Input → QC → Population / Relatedness checks → Association → Results interpretation
